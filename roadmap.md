# Roadmap

We work in four phases, and an open-source track runs alongside them. Everything learned in phases 1–3 gets published here.

| Phase | Goal | What we'll publish |
|---|---|---|
| **1 · Define** | Agree on roles, scope and the product track | This site, the plan, the "why" |
| **2 · Learning path** | A structured 30/60/90-day skills plan | [Curriculum]({{ '/curriculum/' | relative_url }}) |
| **3 · Hands-on lab** | Practice environment and starter exercises | [Labs]({{ '/labs/' | relative_url }}), synthetic data generator |
| **4 · Placement** | Learner contributes on real engagements | Lessons learned (no client details) |
| **★ Open source & AI** | Tools that lower the barrier for everyone | [AI companion]({{ '/ai/' | relative_url }}), API tooling ideas |

## Ground rules

- **Original content only.** We link to official SailPoint documentation and training; we don't copy it.
- **Synthetic data only.** Nothing from any customer environment: no configs, names, screenshots or data.
- **AI is labeled.** When AI helped write something, we say so, and a human reviews it.
