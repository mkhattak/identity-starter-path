# Identity Starter Path

A free, open, hands-on path to becoming a SailPoint identity engineer, built in public with help from AI.

**Site:** https://mkhattak.github.io/identity-starter-path *(once Pages is enabled)*

## What's here

| Path | Contents |
|---|---|
| `curriculum/` | 30/60/90-day learning path |
| `labs/` | Hands-on exercises with solutions |
| `ai/` | Study companion prompts and AI tooling |
| `_posts/` | Weekly learning log |

Planned: `data/` (synthetic identity data generator).

## Run locally

```bash
bundle install
bundle exec jekyll serve
# open http://localhost:4000/identity-starter-path/
```

Every push to `main` deploys to GitHub Pages via `.github/workflows/pages.yml`.

## Ground rules

- Original content only. Link to official SailPoint docs; don't copy them.
- Synthetic data only. Nothing from any customer environment.
- AI-assisted content is labeled and reviewed by a human.
