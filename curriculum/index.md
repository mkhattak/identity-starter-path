# Curriculum

<span class="badge">Draft outline</span>

A 30/60/90-day path. Each module will link to official docs, a lab and a short self-check.

## Days 1–30 · Foundations
- IAM fundamentals: identities, accounts, entitlements, joiner-mover-leaver (JML)
- Access models: RBAC, access profiles, separation of duties (SoD)
- Access reviews and certifications: why auditors care
- Getting around the SailPoint platform

## Days 31–60 · Building
- Connecting sources: Active Directory, Entra ID, a database, a flat file
- Identity profiles, attributes and transforms
- Roles and access profiles
- Rules: when you need them and when you don't

## Days 61–90 · Operating
- Workflows and lifecycle automation
- Running certification campaigns end to end
- Troubleshooting: aggregation errors, correlation, provisioning failures
- Putting it together: a capstone scenario using synthetic data

*Detailed modules are coming soon.*
